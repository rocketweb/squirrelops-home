## What is new in SquirrelOps Home 2.0.0

SquirrelOps Home 2.0.0 is the new baseline for the redesigned desktop app,
privileged networking boundary, and sensor platform. It replaces the
unreleased 1.1.15 version number.

### Desktop experience

- The macOS app has a complete in-app help guide, native alert notifications,
  reliable dashboard activation, and a compact menu when there are no alerts.
- Alert, decoy, Squirrel Scout, settings, pairing, and connection behavior have
  been substantially rebuilt since the long-lived 1.1.3 release.
- Optional LLM device classification supports LM Studio, Ollama, OpenRouter,
  Fireworks.ai, and custom OpenAI-compatible endpoints.

### Sensor and deception platform

- Fake hosts now accept bare names, `.local`, and `.localdomain` names while
  publishing valid Bonjour identities.
- Alert retention, incident grouping, scanner behavior, virtual IP isolation,
  pairing, authenticated API access, and database migration safety have been
  substantially hardened.
- Home Assistant `.local` connections accept normal interface-scoped private
  IPv6 answers while unsafe mixed answers remain blocked.
- Linux runs the sensor without capabilities on a private bridge. A separate
  constrained helper holds only `NET_RAW` and `NET_ADMIN`, authorizes the fixed
  sensor UID over a Unix socket, and exposes no arbitrary command execution.

### Independent component versions

The Home distribution, macOS app, and sensor each have an independent semantic
version. This initial 2.0.0 release aligns them at the new platform boundary;
future releases may update one component without renumbering the others.

Compatibility is determined by an explicit sensor API protocol, not by assuming
the app and sensor version strings match. The 2.0.0 app and sensor use sensor API
protocol 2.

App component source is identified by protected `app-v*` tags. Linux sensor
images are released independently under `sensor-v*` tags. Home distribution
packages are released under `home-v*` tags and record the exact app and sensor
versions they contain.
