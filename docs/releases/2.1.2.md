## What is new in SquirrelOps Home 2.1.2

Home 2.1.2 corrects the operator documentation and the help shipped inside the
macOS app. It includes app 2.1.1 and sensor 2.1.1.

### Corrected in-app help

- Squirrel Scouts probes discovered LAN services inside the sensor. The help
  now describes Run Scout and Fill Capacity instead of a remote-agent
  enrollment and revocation workflow that is not implemented.
- Automatic behavioral-baseline collection is not active. The help no longer
  describes initial learning as a running monitoring feature.
- Classic File Share, Dev Server, and Home Assistant decoys are HTTP
  presentations. Studio Build Mac provides real SSH/SFTP and Samba inside a
  disposable Linux guest with macOS-shaped content. Its model and MCP APIs
  return synthetic results.
- Operator tests and legitimate scanners can trip decoys. Supported HTTP
  requests that submit recognized bait can produce Critical alerts;
  downloading bait alone is ordinary decoy activity. SSH/SMB relays record
  connections rather than authentication or file operations.
- Device-change events do not automatically create alert-feed rows. DHCP
  fingerprints can be supplied to classification, but this scanner does not
  collect them.
- Home Assistant enrichment uses validated private-LAN destinations. Optional
  cloud AI and external alert delivery are described separately from local
  storage and native Mac notifications.

### Documentation and installation

The README, user guide, security model, development guide, and decoy-depth
documentation now describe the implemented protocols, data storage, and
notification limits. The README and helper diagrams have aligned walls.
Package verification follows the attested release document for the selected
published Home version, with exact workflow and signed-tag source pins.

This release changes help and documentation. The embedded sensor, guest
protocols, dependency locks, and isolation boundary retain the Home 2.1.1
implementation. macOS 14 or later on Apple Silicon remains required.
