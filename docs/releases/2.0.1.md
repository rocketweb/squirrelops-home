## What is new in SquirrelOps Home 2.0.1

SquirrelOps Home 2.0.1 is the first published release of the redesigned
desktop app, privileged networking boundary, and sensor platform. It replaces
the unpublished 2.0.0 release attempt and fixes the remote release-control
checker's handling of GitHub's `current_user_can_bypass` string enum.

### Desktop experience

- The macOS app has a complete in-app help guide, native alert notifications,
  reliable dashboard activation, and a compact menu when there are no alerts.
- Alert, decoy, Squirrel Scout, settings, pairing, and connection behavior have
  been substantially rebuilt since the long-lived 1.1.3 release.
- Optional LLM device classification supports LM Studio, Ollama, OpenRouter,
  Fireworks.ai, and custom OpenAI-compatible endpoints.

### Sensor and deception platform

- Fake hosts accept bare names, `.local`, and `.localdomain` names while
  publishing valid Bonjour identities.
- Alert retention, incident grouping, scanner behavior, virtual IP isolation,
  pairing, authenticated API access, and database migration safety have been
  substantially hardened.
- Home Assistant `.local` connections accept normal interface-scoped private
  IPv6 answers while unsafe mixed answers remain blocked.
- The macOS package keeps privileged networking behind a narrowly authorized
  helper boundary.

### Release integrity

- Protected `app-v2.0.1`, `sensor-v2.0.1`, and `home-v2.0.1` tags identify the
  exact independently reviewed component and distribution source.
- The release workflow requires exact protected-main and tag alignment,
  independent environment approval, signed and notarized packaging, stapling,
  Gatekeeper validation, checksummed assets, attestations, and immutable
  publication.
- GitHub ruleset bypass capability must be the exact safe enum value `never`.
  Missing or bypassable values fail closed.
- Linux publication remains blocked. The `sensor-v2.0.1` tag identifies the
  embedded sensor source but does not publish a Linux image.

### Independent component versions

The Home distribution, macOS app, and sensor each have an independent semantic
version. This release aligns them at 2.0.1; future releases may update one
component without renumbering the others.

Compatibility is determined by sensor API protocol 2, not by assuming the app
and sensor version strings match.
